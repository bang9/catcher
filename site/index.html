Your agents ask. Your phone answers.

catcher is a private line between your phone and the AI agents that work for you: Claude Code, Codex, your own bots, a cron job. Any agent with a shell can use it as one of its own messaging channels.

$ catcher ask "Merge PR 12?" --choices yes,no --wait
waiting for your answer…
yes

pickle asks

Merge PR 12?

yesno

  1. Agent asks, you answer

    An agent that needs a decision runs catcher ask or catcher confirm. Your phone buzzes, you tap an answer, the agent carries on. A “no” comes back as exit code 5, so scripts stop on their own.

  2. SMS codes, handed over

    A login wants the code that just arrived by text. The agent runs catcher otp --for naver --wait, you type the code in the app, and only that agent gets it.

  3. Agents talk through grants

    Agents reach each other only through grants you approve, narrow to a scope and optionally held for your release. You see every message between them and can revoke an agent or a grant at once.

Set it up by asking

Tell your agent: Read https://catcher.bang9.dev/agent.md and install catcher.

The agent installs the CLI, registers itself and shows you a link. Open the link on your phone, check the name, approve. That is the whole setup.

Or install it yourself

curl -fsSL https://catcher.bang9.dev/install.sh | sh
catcher register --name pickle

macOS and Linux. On Windows, or anywhere with Node 20+, use npm i -g catcher-cli. The CLI is a single 1.6 MB binary that starts in a few milliseconds.

What the relay can and cannot do

The relay is a thin mailbox. It is honest about what it sees, and the protocol makes sure that is all it gets.

Read the threat model

  • Message content is end-to-end encrypted. The relay stores ciphertext and deletes it once both sides have it.
  • Messages, answers, agent certificates, grants and revocations are signed. The relay cannot forge any of them.
  • Your owner key is created on your phone and never leaves it. Agents keep their own keys on their machine.
  • The relay does see metadata: who talks to whom, when, message types and sizes, agent names. It can delay or withhold delivery; the app shows the gaps.
  • A registration code is a secret until it is used. Whoever claims it first gets the agent, so the agent shows it only to you, and you approve only an agent you just started.
